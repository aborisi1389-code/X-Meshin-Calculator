# 🧮 X-Meshin Calculator

A simple command-line calculator built with Python.

## ✨ Features

- ➕ Addition (`+`)
- ➖ Subtraction (`-`)
- ✖️ Multiplication (`*`)
- ➗ Division (`/`)
- 🔢 Power (`^`)
- 📊 Modulo (`%`)
- ⚠️ Error handling (ValueError, TypeError, OverflowError)
- 🛡️ Division by zero protection
- 🔄 Continuous loop until user exits

1. Make sure Python 3 is installed.
